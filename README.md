# How to use
1. Open [this](https://www.tutorialspoint.com/compilers/online-html-editor.htm) link in a new tab. (or use another online HTML editor)
2. Paste the entire **index.html** file into the code box. (rename the file to have a .txt extension, then open it in a web browser. once it fully loads do CTRL+A and CTRL+C to copy all of it)
3. Click the small green circular "fullscreen" button, next to the red and yellow buttons.
4. Congratulations! You now have an awesome games site right at your fingertips.

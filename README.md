# How to use
1. Open [this](https://www.tutorialspoint.com/compilers/online-html-editor.htm) link in a new tab. (or use another online HTML editor)
2. Click the **index.html** file. Once it loads, press the copy button.
3. Paste the copied **index.html** file into the code box.
4. Click the small green circular "fullscreen" button, next to the red and yellow buttons.
5. Congratulations! You now have an awesome games site right at your fingertips.
